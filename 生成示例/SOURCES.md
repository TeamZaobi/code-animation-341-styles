# DeepSeek Harness 生成示例

本目录的 109 个静音六秒动画由 DeepSeek Harness（界面显示 DeepSeek-V4.1-Flash · High）根据冻结风格提示词生成，用于选型，不是原作者或原项目提供的样片，也不保证未来主题的生成效果。每项的原文摘要、风格依据、局限、文件路径和 SHA-256 保存在 生成示例/source-lock.json。

来源：来自俯仰观照博主的动画画风整理。M/K/Z/H 部分遵循所附 LICENSE-NONCOMMERCIAL.txt；V 系列保留 Vincentwei1021 的 MIT 声明（LICENSE-V-MIT.txt）。安装后的相对来源路径为 风格提示词/。

Codex 接入前独立核对全部 ID/来源/三类文件哈希、实际解码 GIF 和 PNG，并查看五张系列总览（缩略图级检查）；代表性浏览器交互另行抽检。没有逐帧、逐项进行人类专家风格评分。3D、材质等均为代码近似，声音导向风格在静音预览中只能体现视觉节奏；各项具体局限随预览展示。

画廊默认显示海报，用户打开时才加载 GIF；支持打开完整 HTML 查看播放、重播和时间轴。

接入时 Codex 修改了 109 份 HTML 共用的播放控制：暂停会取消待执行动画帧，防止快速播放/暂停时重复循环。未改动场景绘制和 GIF/海报；原始 DSH HTML 哈希另存为 delivered_html_sha256，接入版哈希见 sha256 清单。
